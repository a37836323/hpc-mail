# 写邮件

> 继承 `../MASTER.md`。用户可用任意合法前缀与任意已配置、已授权域名组合发件；固定邮箱不是前置条件。

## 1. 容器与路由

- 使用 route-backed Compose：桌面表现为大型 Dialog，移动表现为全屏 Sheet；URL 可恢复草稿。
- 桌面宽 `min(760px, calc(100vw - 48px))`，高不超过 `calc(100dvh - 48px)`。
- 移动占满 `100dvh`，顶部标题与底部发送栏 sticky 并尊重安全区。
- 打开后聚焦首个缺失字段；关闭有未保存内容时确认，关闭后回到触发按钮。

## 2. 信息结构

```text
写邮件                                        最小化  关闭
─────────────────────────────────────────────────────
发件人名称 [HPC Mail       ]
发件地址   [billing        ] [@hpc.email       ▾]
           billing@hpc.email · 可发送
收件人     [alice@example.com ×                  ]
主题       [七月账单                              ]
─────────────────────────────────────────────────────
正文编辑器
─────────────────────────────────────────────────────
附件  invoice.pdf  1.2 MB  已上传
添加附件                 已保存 14:32       [发送邮件]
```

- 发件区始终可见，不隐藏在“更多”中。
- 输入顺序：显示名称（可选）、前缀、域名、收件人、主题、正文、附件。
- 桌面允许折叠显示名称，但首次使用和验证错误时自动展开。

## 3. 发件身份

值模型：

```ts
type FromIdentity =
  | { mode: 'dynamic'; name?: string; localPart: string; domain: string }
  | { mode: 'mailbox'; name?: string; mailboxId: string };
```

- Dynamic 是默认能力：`localPart` 可编辑，`domain` 只能从当前用户已授权、平台已配置域名选择。
- 如果产品暴露固定邮箱模式，它只是便捷选项，必须与 Dynamic 明确二选一。
- 实时预览最终地址，例如 `billing@hpc.email`；预览不是新的邮箱账户。
- 最近使用地址可以一键填充，但只保存非敏感偏好，不代表已注册邮箱。
- 回复优先使用原邮件实际收件地址；无域名权限时提示并要求选择其他授权域名。

前缀在 blur 后校验：必填、≤64 字符、不以点开头/结尾、无连续点、仅接受后端支持字符。域名选项为空时显示权限说明，不提供自由文本绕过。

## 4. 收件人、主题、正文与附件

- 收件人使用可访问 TokenInput，支持逗号、分号、空格和 Enter；粘贴多地址先预览解析结果。
- 无 Cc/Bcc 后端能力时不展示虚假入口。
- 主题单行，空主题发送前确认，但不强制阻止。
- 正文编辑器使用 React-owned adapter；工具栏支持键盘，输出经过发送侧安全规范处理，不保留旧编辑器兼容 API。
- 附件行显示文件名、大小、进度、取消和重试；上传失败不清空正文。
- 达到大小/数量限制时，在选择阶段和服务端响应后都给出明确上限。

## 5. 草稿与发送

- 输入变化 2 秒 debounce 自动保存；状态为“正在保存 / 已保存 14:32 / 保存失败，重试”。
- 离线草稿保存在本地受控存储，恢复网络后明确提示同步；不同账户草稿隔离。
- `Ctrl/Cmd + Enter` 打开发送确认或直接发送（由用户偏好决定）；默认首次使用需确认快捷键。
- 发送过程区分“正在上传附件”和“正在发送”，按钮保持宽度并禁用重复提交。
- 成功后关闭并提供“查看已发送”；失败保留全部字段，聚焦错误摘要或首个无效字段。
- 删除草稿位于更多菜单/底部次要区，使用 AlertDialog 写明主题且不可与发送相邻。

## 6. 响应式与键盘

- 移动端发件人前缀和域名可上下排列；最终地址必须完整换行显示。
- 软键盘出现时，编辑区缩放而不是把发送按钮推离屏幕；正文仍可全屏编辑。
- Tab 顺序符合视觉顺序；地址 Token 可用方向键移动、Backspace 删除并播报。
- Esc 关闭下拉→关闭编辑器；不能一步丢弃未保存草稿。
- 附件上传进度使用 `aria-live="polite"`，不要逐百分比高频播报。

## 7. 状态与验收

- 域名加载：保持前缀可输入，域名 Select 骨架且发送禁用。
- 无授权域名：说明“当前账户没有可用于发件的域名”，提供联系管理员/返回。
- 429：显示可重试时间，草稿继续保存。
- [ ] 无固定邮箱也可用合法前缀 + 授权域名发件。
- [ ] 无法从未配置、未授权域名发件。
- [ ] 发送失败、离线、关闭重开均不丢草稿。
- [ ] 桌面键盘与 320px 移动触屏均可完成完整流程。
