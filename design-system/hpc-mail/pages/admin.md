# 管理后台

> 继承 `../MASTER.md`。管理后台覆盖分析、用户、全部邮件、角色权限、注册密钥、API 控制和系统设置；所有入口按权限呈现。

## 1. 信息架构

桌面复用全站主侧栏，在“管理”组下展示有权访问的模块。管理主区不保留邮件列表列。

```text
主导航 224px | 管理页 Header（标题/说明/主操作）
             | 二级 Tabs 或本页筛选
             | 数据/表格/配置表单
```

- 权限不足的导航入口可隐藏；直接访问深链路必须显示 403 解释与返回路径。
- 一个页面只有一个主操作，例如“创建用户”“创建密钥”；导出、刷新为次要操作。
- 分析指标使用平面分区，不做同尺寸卡片墙；趋势优先折线、比较优先条形。

## 2. 管理页面通用模式

### Header

- h1、1 行用途说明、右侧主操作；移动端主操作换到标题下方或底部固定区。
- 长任务显示最近更新时间和刷新状态，不在每个区块重复刷新按钮。

### FilterBar

- 搜索、状态、角色/域名、时间范围；激活筛选显示数量与“清除筛选”。
- 筛选写入 URL；返回、刷新、分享后保持。
- 复杂筛选桌面 Popover、移动 Sheet；不在窄屏堆满输入框。

### DataTable

- sticky 表头、真实排序语义、固定操作列；行点击与行内操作不得嵌套冲突。
- 手机转为信息列表：主标识、状态、两项关键数据，更多信息进入详情 Sheet。
- 批量操作出现后写明已选数量；破坏性批量操作二次确认。

## 3. 模块规范

### 分析

- 第一层只显示 3–4 个关键指标：邮件总量、收件、发送成功率、活跃邮箱；带时间范围。
- 图表同时提供可访问摘要和数据表；不使用红/绿作为唯一系列差异。
- 空图表解释数据如何产生；加载显示图表骨架，不展示空坐标轴。

### 用户与角色

- 用户主标识是用户名 + 显示名称，不以某邮箱作为用户标题。
- 邮箱数量是独立数据列；详情内展示邮箱集合。
- 角色权限按功能分组，Checkbox 组有 legend；保存前展示新增/移除权限摘要。
- 不允许删除当前最后一个超级管理员，前后端均校验并解释。

### 全部邮件

- 明确标注“平台范围”，与个人收件箱视觉区分；默认不自动暴露正文预览。
- 搜索与筛选支持用户、邮箱、方向、状态和日期；敏感查看写入审计（后端支持时）。
- 删除邮件必须显示主题、发件人和不可恢复后果。

### 注册密钥

- 创建流程只收集必要权限、有效期、使用次数；生成结果仅展示一次时明确提示复制。
- 列表永远展示掩码、状态、创建者、使用量和到期时间，不回显完整秘密。

## 4. API 控制与浏览器密钥测试

### 密钥列表/创建

- 展示名称、绑定用户、Scopes、限流、到期、最后使用、状态；完整密钥仅创建后展示一次。
- 创建表单渐进披露 IP 白名单、到期与限流；Scope 使用解释性 Checkbox，不只显示内部代码。
- 停用可恢复，吊销不可恢复；使用不同文案与确认层级。

### 密钥测试台

放在 API 控制页面独立 Tab“测试密钥”，从当前浏览器直接调用当前站点 `/api/v1`：

- 密钥使用 password 输入，仅存在 React 组件内存；禁止 URL、日志、localStorage、sessionStorage、缓存和遥测。
- 使用独立原生 `fetch`，不得复用平台 Axios/会话客户端。
- 固定同源 base URL；`credentials:'omit'`、`cache:'no-store'`、`referrerPolicy:'no-referrer'`、AbortController 超时。
- 测试项：状态、邮箱列表、全部收件、按邮箱收件、邮件详情、确认后的测试发信。
- 发信测试支持两种互斥身份：已注册 `mailboxId`，或 `localPart + domain`；域名从 API 返回的授权集合选择。
- 发信前展示完整 From/To/Subject 摘要并二次确认，禁止默认收件人或静默发送。
- 结果只用文本/`<pre>` 渲染截断并转义的 JSON，禁止 `dangerouslySetInnerHTML`。
- 展示 HTTP 状态、Request ID、限流头、耗时；提供复制结果（自动掩码密钥）。
- 关闭 Tab、路由离开或测试结束后可一键清空密钥；创建密钥成功弹层提供“立即测试”。

错误要映射为可行动文案：全局 API 关闭、Scope 不足、IP 不允许、过期、已吊销、限流、绑定用户权限不足。

## 5. 系统设置与飞书 Webhook

- 配置按“站点 / 邮件域名 / 收发策略 / 通知 / 安全”分组；使用侧栏锚点或 Tabs，不堆成超长卡片流。
- 飞书通知位于“通知”：启用开关、Webhook（密码输入/掩码）、签名 Secret（可选/掩码）、邮件规则、保存、发送测试。
- Webhook Helper 明确只接受飞书/Lark 官方机器人地址；已保存值只显示掩码，不从 API 回传明文。
- “发送测试”只使用服务端已保存配置，按钮文案清楚；结果显示成功或具体恢复动作。
- 关闭开关不删除配置；删除配置使用独立危险操作。
- 域名配置使用可编辑表格/列表：域名、状态、验证、配额；添加域名是页面唯一主操作。

## 6. 响应式、状态与权限

- `<768px` 管理入口从设置进入；模块切换使用 Select，不把 7 个 Tab 横向挤压。
- 表单底部保存栏 sticky 时必须预留内容 padding 和安全区。
- 大表格加载使用固定 8 行骨架；增量操作只更新目标行。
- 空状态区分未配置、筛选无结果、无权限；无权限不能伪装成空数据。
- 保存失败保留草稿；并发版本冲突提示刷新或对比，不直接覆盖。
- 所有秘密默认掩码、复制动作可审计、不进入前端错误日志。

## 7. 键盘与无障碍

- `/` 聚焦搜索；表格表头排序、分页、行操作均可 Tab/Enter 操作。
- Dialog/Sheet 焦点陷阱正确，关闭回到触发器；危险确认焦点默认落在取消。
- 图表有文本摘要和表格替代；状态不只使用颜色。
- API 测试结果区域 `aria-live="polite"`，长 JSON 不自动抢焦点。

## 8. 验收

- [ ] 权限控制覆盖导航、页面、操作和服务端，不只隐藏按钮。
- [ ] 用户身份与邮箱地址彻底解耦。
- [ ] API 密钥可在浏览器安全测试，且不持久化、不覆盖平台 JWT。
- [ ] 密钥可查看绑定用户全部收件箱，并按邮箱筛选；发信支持固定邮箱或任意授权前缀+域名。
- [ ] 飞书 Webhook 可保存、掩码、启停并发送服务端测试。
- [ ] 手机可完成核心管理任务，无页面级横向滚动。
