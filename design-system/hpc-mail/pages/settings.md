# 个人设置

> 继承 `../MASTER.md`。设置面向平台账户与个人偏好，不把任何邮箱地址展示为账户身份。

## 1. 页面结构

桌面最大内容宽度 880px，使用左侧锚点导航或顶部 Tabs；移动为单栏连续分区。

```text
设置
账户资料
  用户名          riba2534（只读）
  显示名称        HPC Mail 管理员          [修改]
  密码                                      [修改密码]

偏好
  语言            简体中文 ▾
  主题            跟随系统 ▾
  列表密度        默认 ▾
  键盘快捷键      开启  [查看快捷键]

危险操作
  删除平台账户                              [删除账户]
```

- 使用分隔线和行分组，不为每个字段制作卡片。
- 页面只显示用户名、显示名称、密码和偏好；**不显示 `admin@hpc.email` 或“默认邮箱”行**。
- 邮箱管理若存在，应是独立“邮箱”功能或明确子页，不混入账户身份资料。

## 2. 平台账户资料

- 用户名只读，并用文字“登录用户名”解释；不要以 disabled Input 伪装可编辑。
- 显示名称独立更新平台用户资料，不调用邮箱重命名 API、不需要 mailbox/account ID。
- 内联编辑显示名称：修改→输入+保存/取消；保存中禁用重复提交，失败保留输入。
- 修改密码使用 Dialog：当前策略需要时显示旧密码；新密码要求持续可见；支持密码管理器。
- 修改成功使用 Toast，当前会话是否失效由安全策略明确说明。

## 3. 偏好

- 语言切换即时保存；如果必须刷新，先保存并恢复当前路由/滚动。
- 主题选项：跟随系统、浅色、深色；预览与选择状态不只靠颜色。
- 列表密度：紧凑/默认/舒适，仅影响信息密度，不影响 44px 点击区域。
- 快捷键提供开关和帮助 Dialog；冲突快捷键允许关闭。
- 每项设置保存失败就地显示并回滚到已确认值，不静默失败。

## 4. 危险操作

- “危险操作”与普通设置至少间隔 48px并有分隔线。
- 删除平台账户必须写明影响：账户、邮箱关联、邮件、密钥等是否删除；不得只写“删除所有数据”。
- AlertDialog 要求输入用户名二次确认（若产品安全策略采用），按钮文案“永久删除账户”。
- 退出登录不是危险删除，不使用红色。

## 5. 响应式与无障碍

- 桌面设置行可为 `160px + minmax(0,1fr)`；移动转单列，标签在值上方。
- 输入、Select、按钮均 ≥44px；长显示名称和语言名称允许换行。
- Dialog 打开/关闭正确管理焦点；字段错误与输入关联。
- 成功 Toast 用 polite live region；删除警告使用 `role="alertdialog"`。
- 200% 缩放下操作不被右侧列裁切。

## 6. 状态与验收

- 加载：各设置行固定高度骨架，不先展示错误默认值。
- 保存：只锁定当前设置项，不冻结整页。
- 错误：保留用户输入并提供重试；401 转登录且记住返回设置页。
- [ ] 页面源码和请求不依赖 default mailbox/account。
- [ ] 修改显示名称不会改变任何邮箱名称。
- [ ] 320px 无横向滚动，危险操作不会误触。
- [ ] 账户身份文案始终使用“用户名/平台账户”。
