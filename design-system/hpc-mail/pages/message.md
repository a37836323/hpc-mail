# 邮件详情

> 继承 `../MASTER.md`。目标是忠实、安全、易读地呈现邮件，同时让回复、转发、星标和删除随手可达。

## 1. 布局

桌面作为第三栏显示；平板/移动使用独立 `/message/:id` 路由。

```text
┌ 工具栏：返回 / 删除 / 星标                     回复  转发 ┐
├───────────────────────────────────────────────────────┤
│ 主题                                                   │
│ 发件人  sender@example.com                             │
│ 收件人  inbox@domain.com     2026年7月15日 14:32       │
├───────────────────────────────────────────────────────┤
│ 邮件正文                                               │
├───────────────────────────────────────────────────────┤
│ 附件                                                   │
└───────────────────────────────────────────────────────┘
```

- 详情容器不做居中的“卡片岛”；在详情列内使用分隔线组织。
- 头部 padding 桌面 24–32px、移动 16px。
- 主题 `clamp(20px, 2vw, 28px)`，允许任意断行；元数据使用 `<dl>`。
- 正文阅读宽度默认不超过 920px，但邮件自身固定宽模板可等比缩小。

## 2. 工具栏

- 桌面返回按钮仅在非三栏/深链路场景显示；移动始终显示。
- 主操作是“回复”；转发为 secondary，星标/删除为 IconButton。
- 宽度不足时保留返回、回复，其余进入更多菜单；删除与普通操作分隔。
- 删除需确认并写明主题；成功后返回列表并允许短时撤销（服务端能力允许时）。

## 3. 邮件正文安全与忠实度

`MailBody` 必须使用隔离渲染边界和安全净化：

- 保留安全的 HTML 排版、表格、内联样式、响应式 `@media`、HTTPS `<img>` 与安全 `srcset`。
- 移除 script、事件属性、form/input/button、iframe、object/embed、SVG 活动内容和危险 URL。
- CSS 使用属性白名单；禁止 `url()`、`@import`、远程字体、`position: fixed/sticky`、任意 z-index 与覆盖应用能力。
- 所有外部 HTTP(S) 链接新窗口打开，添加 `noopener noreferrer`；危险/相对执行链接移除 href。
- 远程图片默认显示以还原邮件，强制 `referrerPolicy="no-referrer"`；阅读器菜单提供“停止加载远程图片”，并解释发送方仍可能获知 IP。
- 图片加载、字体完成、容器宽度变化后重新测量；只向下缩放固定宽模板，不放大邮件。
- 图片失败显示不打断布局的占位与 alt；不得因单张图失败隐藏全文。

## 4. 元数据与反钓鱼

- 显示名称和真实地址同时展示；名称与地址域不一致时仍以地址为可信依据。
- 点击发件人打开详情 Popover：完整地址、回复地址、认证摘要（后端提供时）。
- 外链 hover/focus 显示目标域名；不改写链接文字冒充安全域。
- 收件人多于 2 个时折叠为“等 3 人”，可键盘展开。

## 5. 附件

- 附件行展示类型图标、文件名、大小、预览/下载状态。
- 文件名允许两行并可复制；危险扩展名同时显示类型文字，不只靠图标。
- 图片预览使用 Dialog/移动全屏 Viewer；关闭后焦点返回附件行。
- 下载失败就地显示“重新下载”，不只 Toast。

## 6. 响应式与键盘

- 移动工具栏 sticky，并尊重顶部安全区；正文 padding 16px。
- 邮件宽模板缩放后高度同步，不能出现内容裁切或二次横向滚动。
- `r` 回复、`f` 转发、`s` 星标、`j/k` 相邻邮件、Esc 返回列表。
- 切换相邻邮件后聚焦主题并通过 polite live region 播报“已打开下一封邮件”。
- 邮件正文内链接进入正常 Tab 顺序；应用操作始终在正文链接之前。

## 7. 状态与验收

- 加载：头部与正文块骨架；工具栏位置固定。
- 空/404：“这封邮件不存在或已被删除”，动作“返回收件箱”。
- 正文净化失败：显示纯文本内容和“HTML 版本无法安全显示”。
- 远程图失败不等同邮件失败。
- [ ] Apple 等响应式邮件不会重复显示桌面/移动 CTA。
- [ ] 图片与链接正确且安全策略可解释。
- [ ] 320px、200% 缩放和深色模式均可阅读。
- [ ] 单封恶意邮件不会覆盖应用 UI 或触发脚本。
